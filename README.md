# dotnet-recipes

## Задание 1

**Создать консольное приложение для управления рецептами**

### Требования

Рецепт содержит следующие детали:

* Название
* Ингредиенты
* Инструкции
* Один и более категорий


Требования к функциональности:

* Добавление и редактирование категорий рецептов.
* Список, добавление и редактирование рецептов.
* Все данные должны храниться в json-файле на диске.


### Используемые библиотеки

* Для работы с консольным интерфейсом используйте https://github.com/spectreconsole/spectre.console.
* Для сериализации и десериализации JSON используйте System.Text.Json.
